# Домашний покер

Офлайн PWA для ведения домашней кэш-игры на одном телефоне.

## Локальный запуск

Приложению нужен HTTP-сервер для регистрации service worker:

```powershell
python -m http.server 8080
```

Откройте `http://localhost:8080`. Для проверки офлайн-режима сначала откройте приложение один раз при работающем сервере.

## Публикация

Разместите содержимое папки на любом статическом HTTPS-хостинге. На iPhone откройте адрес в Safari и выберите «Поделиться» → «На экран Домой». На Android используйте кнопку установки браузера или кнопку «Установить» в приложении.
